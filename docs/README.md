# 文档索引与写作规则

文档组织规则以仓库根目录 `AGENTS.md` 第 6 节《文档组织与代码注释约定》为准，本文只维护索引和本地细节。

## 目录结构

`docs/` 下按阶段建立子目录 `阶段N-简短名称/`，Markdown 文件名与正文均使用中文。每个阶段目录一般包含：

| 文档 | 内容 |
|---|---|
| 工作记录 | 本阶段做了什么、为什么这样做、与 `TODO.md` 逐项对照的完成度、已知限制、下一步 |
| 复现步骤 | 有序的命令步骤，每步写明工作目录、预期结果和失败时的去向，末尾给出完成判据 |
| 代码说明 | 新增或修改的每个文件做了什么、设计理由、关键细节 |
| 排错记录 | 实际遇到的问题：现象、定位过程、原因、修复、教训；未查清的标为未断言 |
| 验证记录 | 实际运行的证据：源码版本、工具版本、命令、预期、实际、证明了什么、没有证明什么 |

以记录为主的阶段（如阶段 0）可以合并或省略不适用的文档，但要在下表说明原因。
