## 步骤 2：引入上游源码并固定基线

目录不是空的（已有 `AGENTS.md`、`TODO.md`），所以不能直接 `git clone`，改为初始化后抓取：

```bash

git remote add upstream https://github.com/SandOcean-ovo/SandOS.git

```

**如果 `git fetch` 报 `Failed to connect to 127.0.0.1 port 7897`**：这是全局代理失效，临时绕过：


只阅读标签中的原始源码核对历史问题；当前工作区已包含阶段 1/2 的部分修复：


这一步的结论只是“静态阅读所见”，写在《基线与环境记录》第 2 节，**不能写成已复现**。
